# ♟ Шахматы онлайн

Многопользовательские шахматы в реальном времени через Peer-to-Peer WebRTC.

**Ссылка:** https://tx5667604.github.io/chess-game/

## Как играть

1. **Создать игру** — нажмите «Создать игру», скопируйте ссылку и отправьте другу
2. **Присоединиться** — друг открывает ссылку и нажимает «Присоединиться»
3. Играйте! Ходы передаются напрямую между игроками через P2P

## Технологии

- chess.js — логика игры
- PeerJS — WebRTC peer-to-peer
- Чистый HTML/CSS/JS — хостится на GitHub Pages

## Разработка

```bash
# Локально
open index.html
```
